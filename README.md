# 🎬 TMDB Movie Analytics Dashboard

> **Microsoft Fabric Data Day – Power BI Challenge | Round 3**

## 📌 Project Overview

This Power BI dashboard explores one central business question:

> **"What makes a movie successful?"**

Rather than measuring success solely by box-office revenue, this analysis evaluates movies from multiple perspectives including financial performance, audience engagement, profitability, and content quality.

The dashboard analyzes **1M+ movies released between 1900 and 2024** using only the dataset provided for the Microsoft Fabric Data Day Round 3 Challenge.

---

- Movie Release Trend
- Budget vs Revenue Analysis

# 🎯 Key Business Insights

### Financial Performance

- Action and Adventure generate the highest overall revenue.
- Universal Pictures and Warner Bros. Pictures are the strongest performing production companies.
- Higher budgets generally lead to higher revenue, although increased spending does not always guarantee success.
- Some niche genres achieve excellent ROI despite comparatively lower revenue.

### Audience Insights

- Adventure attracts the highest audience engagement through popularity and votes.
- Music and Documentary receive the highest average TMDB ratings.
- Commercial success and audience appreciation are not always the same.
- Drama remains one of the most consistently produced genres over time.

---

# 🚀 Business Recommendations

- Invest more in consistently high-performing genres.
- Balance commercially successful movies with critically acclaimed content.
- Use ROI-driven budget planning instead of increasing budgets indiscriminately.
- Strengthen partnerships with top-performing production companies.
- Leverage audience engagement metrics to improve future content strategies.
- Continuously monitor genre trends to identify emerging opportunities.

# 📌 Responsible Data Use

## Analysis Scope & Assumptions

- Analysis is based only on the provided TMDB dataset.
- Financial metrics use movies with valid Budget and Revenue values.
- ROI = (Revenue − Budget) ÷ Budget.
- Audience analysis is based on TMDB Rating, Popularity, and Vote Count.
- No external datasets or APIs were used.

## Limitations

- Revenue and audience ratings represent different measures of success.
- Missing financial records may affect financial comparisons.
- Findings are limited to the provided dataset.
